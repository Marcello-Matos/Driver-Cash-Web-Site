# Driver Cash - Landing Page

Landing page do aplicativo financeiro Driver Cash, feito para motoristas de aplicativo (Uber, 99 e inDrive) controlarem faturamento, despesas e lucro real.

## Tecnologias

- React 19 + Vite
- Tailwind CSS 3
- Oxlint para analise de codigo

## Como rodar

```bash
npm install
npm run dev
```

## Build de producao

```bash
npm run build
npm run preview
```
